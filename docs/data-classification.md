# Public data classification

| Class | Examples | Public handling |
|---|---|---|
| Public | Generic product requirements, abstract state models, synthetic fixtures, non-sensitive metrics definitions | May be published after review |
| Internal | Unreleased design decisions, provider selection rationale, implementation notes, operational assumptions | Summarize only; do not copy verbatim |
| Restricted | Student/teacher data, real submissions, grades, databases, logs, internal URLs, deployment details | Keep private |
| Never-public | Secrets, credentials, source-recovered educational content, copyrighted material without permission, legal filing/source materials | Exclude permanently |

The public repository uses synthetic examples and product abstractions. A file being technically free of secrets does not make it public: privacy, copyright, contractual confidentiality, and operational sensitivity also apply.
