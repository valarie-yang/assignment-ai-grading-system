# Five-minute demo script

1. Open the synthetic course and assignment.
2. Show the rubric criteria, weights, and score-range validation.
3. Import the synthetic roster and a submission fixture.
4. Move the submission from draft to submitted.
5. Request the structured AI preliminary assessment.
6. Point out criterion evidence, suggested scores, uncertainty, and provider metadata.
7. Edit one criterion as the teacher and add a review note.
8. Show that the reviewed result—not the raw AI output—is used for the final report.
9. Trigger a malformed or failed AI response and show that it cannot write a final grade.
10. End on the evaluation plan and production release gates.

The demo should use synthetic content and a local or sandboxed provider only. It should not expose credentials or send real student data.
